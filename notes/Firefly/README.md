# Firefly notes

Josh's personal Obsidian vault from designing Firefly — working design reasoning, prompt
experiments, and per-model notes (DeepSeek, Ling, etc.) written while figuring things out.

**Historical, not documentation.** Several prompts in here are earlier drafts that have since
evolved into what's actually shipped — compare against the real thing before assuming anything
here reflects current behavior. The code and its live prompt constants (e.g.
`Source/Firefly/Journal/JournalSummaryService.cs`, `Source/Firefly/World/WorldThreadScanIngest.cs`)
are always the authority, never this folder.

Kept for the design history and reasoning, not as a reference to build against.
